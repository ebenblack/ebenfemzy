# Eben Black — Professional Portfolio

A responsive, single-page professional portfolio for Eben Black, positioned as a **Digital Growth & Business Solutions Specialist**.

## What's included

- Responsive portfolio homepage
- About section and professional positioning
- Seven service areas
- A simple three-step working approach
- Email contact call-to-action
- Mobile navigation
- SEO and social sharing metadata
- Reduced-motion accessibility support

## Run locally

This is a lightweight static website with no build step or package installation required.

You can open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy to Vercel

1. Import the `ebenblack/ebenfemzy` repository into Vercel.
2. Select **Other** as the framework preset if prompted.
3. Leave the build command and output directory empty.
4. Deploy.

Vercel can serve this static site directly from the repository root.

## Before publishing

Personalize the portfolio further by adding:
- A professional headshot
- Real project screenshots and case studies
- Verified work experience, qualifications and achievements
- Any additional professional contact or social links you want public

No client results, certifications, work history or testimonials have been invented in this starter portfolio.
